Neste projeto, o objetivo é explorar a aplicação das estruturas condicionais como if-else, switch e a de repetição (While), com elaboração de operações cotidianas e práticas. 

Além dos exercícios resolvidos nas aulas, vocês deverão escolher 5 opções de algoritmos, abaixo, para resolver e subir todos eles em seu repositório no GitHub e postar o link nesta tarefa.

*Exercícios propostos
- Verificador de Paridade: Receba um número e diga se ele é par ou ímpar usando o operador de resto (%).
- Calculadora de Média Escolar: Peça quatro notas, calcule a média e diga se o aluno está "Aprovado" (média $\ge 7$), "Recuperação" (entre 5 e 6.9) ou "Reprovado".
- Maior de Idade: Pergunte o ano de nascimento e informe se a pessoa já pode tirar a CNH ou se ainda precisa esperar.
- Comparador de Números: Receba dois valores e exiba qual é o maior ou se eles são iguais.
- Classificador de Triângulos: Peça os três lados de um triângulo e diga se ele é Equilátero, Isósceles ou Escaleno.
- Contagem Regressiva: Peça um número inicial e faça o computador contar até zero, parando o programa no fim.

- Tabuada Dinâmica: Peça um número ao usuário e use o while para exibir a tabuada dele do 1 ao 10.
- Somador Infinito: Peça números ao usuário e vá somando-os. O loop só para quando o usuário digitar "0".
- Validador de Senha: Crie uma senha mestra. Use o while para impedir que o usuário acesse o sistema até que ele digite a senha correta.
- Média de N números: O usuário decide quantos números quer inserir. O while lê todos e, ao final, mostra a média aritmética.
- Jogo de Adivinhação: O programa escolhe um número aleatório e o usuário tem que adivinhar. O while continua rodando enquanto ele errar, e o if dá dicas de "mais alto" ou "mais baixo".

- Menu de Calculadora: Exiba um menu (1-Soma, 2-Subtração, 0-Sair). Use o while para manter o programa aberto até que o usuário escolha "0".
- Fatorial de um Número: Calcule o fatorial de um número digitado (ex: $5! = 5 \times 4 \times 3 \times 2 \times 1$).
- Verificador de Números Primos: Use um laço para testar se um número é divisível por algum outro além de 1 e dele mesmo.
- Sequência de Fibonacci: Mostre os primeiros $N$ termos da sequência, onde cada número é a soma dos dois anteriores.

- Caixa Eletrônico Simples: Peça um valor de saque e o programa deve dizer quantas notas de R$ 50, R$ 20 e R$ 10 são necessárias (usando subtrações sucessivas no while).
- FizzBuzz: Percorra os números de 1 a 30. Se for múltiplo de 3, imprima "Fizz". Se for múltiplo de 5, "Buzz". Se for dos dois, "FizzBuzz".
Conversor de Moedas Repetitivo: Um programa que converte Real para Dólar quantas vezes o usuário quiser, até ele digitar um comando de saída.
- Analisador de Clima: O usuário insere a temperatura de vários dias. O programa para quando receber uma temperatura impossível (ex: -500) e mostra a maior e a menor temperatura registradas.
- Controle de Estoque: Comece com 10 produtos. O while pergunta se o usuário quer "Comprar" ou "Vender". Atualize o estoque e não deixe vender mais do que o que está disponível.
